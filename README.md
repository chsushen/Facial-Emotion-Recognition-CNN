# Real-Time Facial Emotion Recognition using CNN

## Overview
This project uses a Convolutional Neural Network (CNN) to detect human emotions from facial expressions in real-time.

## Dataset
FER-2013 dataset (35,000+ images)

## Features
- Real-time emotion detection
- Image preprocessing and augmentation

## Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
